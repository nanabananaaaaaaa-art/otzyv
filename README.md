# Telegram-бот для учета отзывов

Минимальный бот для менеджеров:

- менеджер выбирает город;
- отправляет точку/офис, платформу и фото/скрин/ссылку отзыва;
- бот ставит отзыв в статус `на проверке`;
- администратор подтверждает или отклоняет отзыв;
- KPI и заработок считаются автоматически.

Бот не публикует отзывы сам. Он ведет учет и помогает проверять оплату.

## Команды

Для менеджера:

- `/start` - регистрация и выбор города
- `/city` - сменить город
- `/add` - отправить отзыв на проверку
- `/kpi` - посмотреть свой KPI и заработок

Для администратора:

- `/pending` - отзывы на проверке
- `/report` - отчет по менеджерам
- `/approve_НОМЕР` - подтвердить отзыв
- `/reject_НОМЕР` - отклонить отзыв

## Как создать Telegram-бота

1. В Telegram открой `@BotFather`.
2. Напиши `/newbot`.
3. Придумай название бота.
4. Придумай username, он должен заканчиваться на `bot`.
5. BotFather выдаст токен вида `123456:ABC...`.
6. Этот токен надо записать в `.env`.

## Как узнать свой Telegram ID

Самый простой способ:

1. Открой в Telegram `@userinfobot`.
2. Нажми Start.
3. Скопируй свой ID.
4. Запиши его в `ADMIN_IDS`.

Если админов несколько, укажи через запятую:

```env
ADMIN_IDS=123456789,987654321
```

## Локальный запуск

Нужен Python 3.12.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Потом открой `.env` и замени:

```env
BOT_TOKEN=сюда_токен_от_BotFather
ADMIN_IDS=твой_telegram_id
DEFAULT_REVIEW_PRICE=100
DATABASE_PATH=bot.sqlite3
```

Запуск:

```powershell
python -m app.main
```

## Запуск на Amvera

Для Amvera в проекте уже есть `Dockerfile`.

Обычно порядок такой:

1. Загружаешь проект в GitHub или прямо в Amvera, если используешь загрузку архива.
2. В Amvera создаешь приложение из Dockerfile.
3. В переменных окружения добавляешь:
   - `BOT_TOKEN`
   - `ADMIN_IDS`
   - `DEFAULT_REVIEW_PRICE`
   - `DATABASE_PATH=bot.sqlite3`
4. Запускаешь приложение.

Если Amvera попросит команду запуска, укажи:

```bash
python -m app.main
```

## Подробно: запуск через GitHub и Amvera

Схема такая:

1. Код бота лежит у тебя на компьютере.
2. Ты загружаешь код в GitHub.
3. Amvera забирает код из GitHub.
4. Amvera запускает бота на сервере.
5. Бот работает постоянно, пока приложение в Amvera включено.

### Шаг 1. Создать репозиторий на GitHub

1. Открой сайт `https://github.com`.
2. Нажми `New repository`.
3. Название можно сделать, например:

```text
reviews-telegram-bot
```

4. Лучше выбрать `Private`, чтобы код не был публичным.
5. Не добавляй README, `.gitignore` и License на GitHub, потому что эти файлы уже есть локально.
6. Нажми `Create repository`.

После создания GitHub покажет команды для загрузки проекта. Они понадобятся дальше.

### Шаг 2. Загрузить этот проект в GitHub

Открой PowerShell в папке проекта:

```powershell
cd "C:\Users\home\Documents\ChatGPT\Бот Тг для отзывов"
```

Проверь, что Git видит файлы:

```powershell
git status
```

Добавь файлы в коммит:

```powershell
git add .
git commit -m "Initial Telegram reviews bot"
```

Подключи GitHub-репозиторий. Ссылку надо взять со страницы твоего репозитория на GitHub:

```powershell
git remote add origin https://github.com/ТВОЙ_ЛОГИН/reviews-telegram-bot.git
```

Загрузи код:

```powershell
git branch -M main
git push -u origin main
```

Если GitHub попросит логин и пароль, обычный пароль может не подойти. Сейчас GitHub часто просит токен. Проще всего поставить GitHub Desktop или авторизоваться через браузер, если Git сам предложит.

### Шаг 3. Подготовить токен бота

1. В Telegram открой `@BotFather`.
2. Напиши `/newbot`.
3. Придумай название бота.
4. Придумай username, который заканчивается на `bot`.
5. Скопируй токен вида:

```text
123456789:AA.......
```

Токен нельзя отправлять в GitHub. Его надо хранить только в переменных Amvera.

### Шаг 4. Узнать ID администратора

1. В Telegram открой `@userinfobot`.
2. Нажми `Start`.
3. Скопируй свой числовой ID.

Он понадобится для переменной `ADMIN_IDS`.

### Шаг 5. Создать приложение в Amvera

1. Открой Amvera.
2. Создай новое приложение/проект.
3. Выбери запуск из GitHub-репозитория.
4. Подключи репозиторий `reviews-telegram-bot`.
5. В качестве способа сборки выбери Dockerfile, если Amvera спросит.

В проекте уже есть файл `Dockerfile`, поэтому Amvera сможет понять, как запускать бота.

### Шаг 6. Добавить переменные окружения в Amvera

В настройках приложения Amvera найди раздел `Environment variables`, `Переменные окружения` или похожий.

Добавь:

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=твой_telegram_id
DEFAULT_REVIEW_PRICE=100
DATABASE_PATH=bot.sqlite3
```

Если админов несколько:

```env
ADMIN_IDS=123456789,987654321
```

### Шаг 7. Запустить приложение

После настройки нажми Deploy/Start/Запустить.

Если Amvera спросит команду запуска, укажи:

```bash
python -m app.main
```

Если Amvera запускает через Dockerfile, отдельная команда может не понадобиться.

### Шаг 8. Проверить бота

1. Открой своего бота в Telegram.
2. Нажми `Start`.
3. Выбери город.
4. Напиши `/add`.
5. Отправь тестовый отзыв.
6. Админу должно прийти сообщение с командами `/approve_номер` и `/reject_номер`.
7. Подтверди отзыв.
8. Напиши `/kpi` и проверь, что заработок увеличился.

### Частые ошибки

`Set BOT_TOKEN in environment or .env`

Значит в Amvera не указана переменная `BOT_TOKEN` или она названа неправильно.

`Unauthorized`

Значит токен бота неправильный. Скопируй токен из BotFather заново.

Админу не приходят заявки

Проверь `ADMIN_IDS`. Там должен быть именно Telegram ID, не username.

Бот не отвечает

Проверь логи Amvera. Если приложение упало, в логах обычно видно причину.
