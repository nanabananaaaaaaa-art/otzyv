3.4. Источник Avito

Событие создания лида

Событием создания лида является первое входящее сообщение клиента в новом диалоге Avito.

Все обращения из Avito считаются обращениями новых клиентов по продажам. Действующие клиенты через Avito не обращаются, поэтому проверка наличия действующей аренды перед созданием лида не выполняется.

После поступления обращения в ERP создаётся лид с уникальным lead_id.

Параметры источника

- Источник — Avito.
- Канал обращения — Avito.
- Имя клиента — передаётся, если известно.
- Номер телефона — может отсутствовать.
- Город — город объявления.
- Ответственный менеджер — базовое значение «Не назначен».

Передаваемые данные

Avito должна передавать в ERP:

- дату и время создания;
- источник — Avito;
- канал обращения — Avito;
- имя клиента, если известно;
- номер телефона, если известен;
- аккаунт компании на Avito;
- заголовок объявления;
- ссылку на объявление;
- город объявления;
- ссылку на профиль клиента;
- уникальный внешний ID пользователя Avito;
- ответственный менеджер — базовое значение «Не назначен».

ID диалога Avito не передаётся и не сохраняется.

Точное техническое название поля уникального внешнего ID пользователя Avito должен подтвердить IT по текущей интеграции или API.

Исходные данные, полученные из Avito, сохраняются в карточке лида бессрочно и без изменений.

Повторные обращения

При новом обращении ERP проверяет наличие лида с таким же уникальным внешним ID пользователя Avito.

- Если существует лид со статусом, отличным от «Закрыт», новый лид не создаётся. Информация о повторном обращении добавляется в карточку существующего лида.
- Если существующего лида нет либо предыдущий лид имеет статус «Закрыт», создаётся новый лид с уникальным lead_id.

Правило применяется независимо от того, написал клиент:

- повторно в тот же диалог;
- по другому объявлению;
- через другой аккаунт компании;
- после закрытия предыдущего лида.

ID диалога в проверке не участвует.

Связь с user_id

Первоначально лид Avito создаётся без номера телефона и связанного user_id, если номер телефона клиента неизвестен.

Если в процессе общения становится известен номер телефона клиента, он добавляется в рабочее поле карточки лида и приводится к единому формату ERP.

После этого ERP выполняет стандартный поиск:

- если user_id с таким номером найден, lead_id связывается с существующим user_id;
- если user_id не найден, поле связанного user_id остаётся пустым;
- если клиент позднее самостоятельно создаёт личный кабинет с этим номером, ERP автоматически связывает существующий lead_id с созданным user_id.

Создание лида и добавление номера телефона не создают новый user_id.
